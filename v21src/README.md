# App Volume Buttons v2.1

Samsung/Shizuku per-app volume controller.

- Physical volume buttons target the foreground app.
- Samsung native per-app volume changes by exactly 1 percentage point per press.
- Main Media volume is not changed.
- Samsung's normal Media volume panel is requested at the current unchanged Media level.
- A small app-specific popup shows the per-app percentage.
- Home/System UI are left alone.
